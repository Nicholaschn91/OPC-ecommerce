【Etsy SEO 通用铁律（去商品化 · 适用于一切 Etsy listing）】
> 以下 4 条为跨商品通用原则，每条 listing 默认强制遵循，不因具体品类而豁免：
>
> 1. **语言与拼写一致性**
>    · 按店铺主力客群地区，全文统一一种拼写体系（英式/美式二选一，默认美式）。
>    · 非主推市场的拼写变体只允许出现在 **Tags** 作补充捕获；标题与 Description 正文核心位置禁止混用，避免语义混淆、分散流量权重。
>
> 2. **标题前部权重分配（前 40 字符最高权重）**
>    · 排序逻辑：「核心差异化卖点/材质 + 精准场景/人群词 + 品类大词」。
>    · 最具辨识度、转化率最高的长尾词前置；宽泛品类大词后置兜底匹配，确保搜索结果第一眼即可识别产品独特性（与【意图三层分桶】交易型意图前置一致）。
>
> 3. **Tags 格式规范**
>    · Tags **直接用空格分隔词组**，禁止连字符/下划线（"custom canvas bag" ✅ / "custom-canvas-bag" ❌）。
>    · 用满全部 13 个 Tag；优先覆盖**标题未包含**的同义词/近义词/场景词/属性词，实现矩阵互补而非重复。
>    · 除最高转化尖刀词（T4#1）作锚点保留外，禁止把标题已有词组原样搬进 Tags 造成字符浪费。
>
> 4. **关键参数量化（Description 必备，但只许照抄真实数据）**
>    · 禁止只堆主观形容词（"大容量"/"耐用"/"精致"）；须补充行业通用**可量化客观参数**：尺寸、重量、容量、材质规格（克重/支数）、印刷工艺、洗护方式等。
>    · 量化信息既是用户信任基础，也是搜索引擎区分同类、匹配细分需求的核心依据。
>    · **🚫 反幻觉铁律（最高优先级）**：以上参数**只能来自数据段里的 `specs` 真实块**。数据段若没有 `specs`，则【Specifications】段落整体省略，**绝不允许模型自行编造尺寸/克重/承重/洗护**——编造的"客观参数"比主观形容词更危险（误导买家、引发售后纠纷、违反平台诚实政策）。
>    · **渲染格式（人读 + AI 提取双友好，固定四行标签；仅渲染数据段中实际存在的项，缺哪项省哪行）**：
>      📐 Size: 38 × 35 × 10 cm
>      🧵 Material: 100% cotton canvas, 12 oz
>      🎨 Print: Water-based screen print, fade-resistant
>      🧼 Care: Spot clean or gentle machine wash, air dry

【Etsy GEO 专项指北 — 描述与意图】（Step 3 核心执行规则）
> 标题受 140 字符限制，操作空间有限；GEO 的主战场是 Description + Tags 的语义布局与搜索意图匹配。以下规则**只针对 Description（Step 3）与 Tags 部署**，标题仍按 Step 1 前 40 字符规则。
>
> **意图三层分桶**（Etsy 搜索 AI 按用户搜索意图分桶匹配）：
> · **交易型意图**（buy/order/get）：品类词 + 用途词（如 "custom wooden plaque"、"first day of school sign"）→ 必须出现在**标题前 40 字符**与**Description 前 3 句**
> · **信息型意图**（how/what/ideas）：场景联想词 + 使用方法 + 情感场景 → 部署在 Description 主体段（中段）
> · **导航型意图**（brand/category/occasion）：礼赠场景词 + 节日词 + 受众词 → 主要放在 **Tags** 中（13 个用满），Description 段尾呼应
>
> **Description 段落语义权重布局**（按 Etsy 搜索 AI 索引权重排序）：
> 1. **前 160 字符**（约前 3 句）：最高权重，AI 搜索结果摘要抓取区 → 必须包含【品类核心词 + 主要属性词 + 1 个情感场景词】
> 2. **中段主体**（300-800 字符）：使用方法 + 卖点细节 + 情感文案 → 用**同义词簇**（不要原词堆叠）覆盖语义相关词
> 3. **段尾**（最后 100-200 字符）：礼赠场景 + 受众 + 节日 → 与 Tags 形成语义互补而非重复
>
> **语义去重规则**：
> · 同一关键词在 Description 中**不连续出现超过 2 次**，间隔至少 50 字符
> · 标题首段已出现的关键词，Description 前 160 字符内必须以**同义词**变体出现（避免堆砌降权）
> · Tags 优先选 Description 末段未覆盖的**长尾变体词**（补充而非重复）
>
> **Tags 硬约束（Etsy 平台规则）**：
> · **数量固定 13 个**，**每个 ≤20 字符（含空格）**——超过 20 字符的 tag 属于无效输出，Etsy 后台会拒收且不参与搜索匹配
> · 首 Tag 必须为最高转化意图词（T4 利润尖刀）；后续 12 个为长尾/场景词（T3 为主）
> · 终版产物中 Tags 字段必须**逐条自检**：每条字符数 ≤20，否则立即改写到 ≤20（截断到最后一个完整词边界，不要硬切中段字母）
> · 多词 tag **直接用空格**分隔词组，禁止连字符/下划线（Etsy SEO 通用铁律#3）："custom canvas bag" ✅，"custom-canvas-bag" ❌；仍须满足每条 ≤20 字符（含空格），超限截断到最后一个完整词边界
>
> **AI 搜索友好的自然语言规则**：
> · Description 是写给「想买这个东西的人」看的，不是写给搜索引擎的——保持自然语句结构
> · 关键属性用**完整短语**而非关键词堆砌（如 "personalized with your child's name" 而非 "personalized custom name engraved"）
> · 每段第一句必须是完整陈述句，包含至少一个意图层关键词
>
> **每条 listing Description 必须覆盖的三类信息（铁律#4 补充量化参数）**：
> · **是什么**：品类 + 材质 + 形态 + **可量化参数（仅取自数据段 `specs`，无则省略，禁止编造）**，前 160 字符内完成，禁止仅用主观形容词
> · **怎么用 / 为什么买**：使用场景关联 + 情感价值（中段）
> · **为谁买 / 什么时候**：受众 + 节日/场合 + 礼赠（段尾）

【基材消费（Step 4 前置，替代原「视觉资产转换引擎」）—— ⚠️ 两阶段分工语义】
> **本环节 = 阶段 1·视觉方案设计**（纯文字输出，不能直接生成图）。下游图生图工具（千问 AI生图/通义万相/即梦）才是**阶段 2·真实出图**。
> 这两段**不能混淆**：
> - **阶段 1（本环节）**：读「基材 spec = 素材清单」→ 输出 **7 段 PROMPT 文字**
> - **阶段 2（图生图技能）**：拿 PROMPT + spec 中指定的对应参考图 → 出 4 张变体
> 两段之间的桥 = **「哪张 PROMPT 对应哪张参考图」**（spec 的 `visual_slots` 字段映射）。
>
> **关键澄清——alt text 的真实用途**：spec 里每张垫图的 alt 不是给最终 PROMPT 用的「视觉描述词素材」，而是给**本环节（阶段 1）的大模型**用的**「可用素材清单」**——让模型在设计 7 段 PROMPT 时**清楚知道有哪些垫图可调度**（角度/材质/颜色/形态）。模型据此：
> 1. 决定 7 段 PROMPT 的角度分布（hero / dtl / opt / inf …）必须与素材清单一一对应；
> 2. 每段 PROMPT 的视觉焦点（材质/颜色/形态/构图/光线/背景）自然落在该角度能呈现的范围内；
> 3. 缺角位（spec 没素材）显式标 `[NEEDS_CAPTURE]`，禁止凭空写 PROMPT。
>
> **不要把 alt 字面照搬进 PROMPT**——alt 是「设计上下文」，PROMPT 是「给图生图工具的执行指令」，两者粒度不同：
> - alt：清单化、客观描述（"Coffee Brown crazy horse leather bifold wallet, front exterior view, contrast stitching visible"）
> - PROMPT：场景化、构图明确、含光线/景深/背景/禁止元素（"A single men's bifold wallet... photographed front-on... on a clean matte charcoal surface... upper-left key light... shallow depth of field..."）
> 模型应**消化 alt 后写出更具体的 PROMPT**，不是翻译 alt。
>
> **本环节只消费 spec（angles[]：path / seq / role / white_bg / alt / size）**：
> 1. 读取 spec 中每张图的角度(role)与已填 alt（材质/颜色/形态）；
> 2. 按 Step 4 的 7 图位规划，将 spec 角度映射到 img1~img7（hero/dtl/opt/inf 等 cat），缺角补 `[NEEDS_CAPTURE]`；
> 3. 据此生成每张的正式 PROMPT/NEGATIVE——**PROMPT 的视觉焦点源自 alt 语义，但扩写为完整场景化执行指令**（光线/构图/景深/背景/比例/禁止元素齐全），保证图案与文案相互呼应；
> 4. SEO 文件名沿用 `{spu}_{variant}_{cat}_{seq}_{semantic_slug}.{ext}`，semantic_slug 由 alt 直译，不重新解析图像。

> **文案↔视觉呼应铁律**：Step 3 Description 主推的卖点/材质/场景词，必须在 Step 4 对应图位 PROMPT 中以视觉元素呈现（如描述 "walnut wood grain" → 图位呈现木纹特写）；反之亦然。文案与图案必须讲同一个故事，Listing 内文案与图案相互呼应。

【垫图白底商品图 alt 详尽度指引——给基材提取执行器】
> 由 00 基材提取执行器产出 alt 时遵循以下原则（用户 2026-08-10 认知）：
> - **详尽程度由大模型自行判断**——不必死板照模板，但必须覆盖以下六维，缺一扣分：
>   1. **材质**：疯马皮 / 真皮 / 实木 / 金属 …（避免用 "high-quality material" 这种模糊词）
>   2. **颜色**：咖啡棕 / 深棕 / 胡桃木色 …（给出具体色名或 hex）
>   3. **形态**：对折钱包 / 矩形挂牌 / 圆形徽章 …（不要只写 "wallet"）
>   4. **构图/角度**：正面 / 侧面 / 平铺展开 / 微距特写 …（决定下游 PROMPT 镜头语言）
>   5. **光线/背景**：自然窗光 / 哑光炭灰背景 / 木纹台面 …（决定下游 PROMPT 场景氛围）
>   6. **关键工艺细节**：对比缝线 / 烫金 logo / 拉丝金属 …（决定下游 PROMPT 视觉焦点）
> - **不杜撰**：alt 只能描述图里**能看见**的元素，禁止补全推断的视觉特征（"vintage patina" 必须真的看得见，否则不写）。
