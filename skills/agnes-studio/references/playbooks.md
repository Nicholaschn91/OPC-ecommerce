# 流程目录 F1–F9（playbooks）

> 流程 = 能力的串联，只在用户给出"目标型结果"时启用。优先整体命中预置流程；预置覆盖不了才动态拼装（custom）。
> 单能力请求禁止进入本节编排（P0 规则 1）。

## 通用规则

1. 任何含生成的流程，若 P1 检出 `copyright_risk` 任一为 true，必须在生成前插入 S2 侵权闸门。
2. 实物生产类流程末尾必须含 S13 交付检查。
3. 产出为多图/系列的流程末尾必须含一致性校验（P11 双阈值）。
4. 复用已有 Asset：上游或历史单能力产出的 mask/透明底/参考图可直接引用，禁止重复计算（P2 规则 7）。
5. 出现人物主体必须含身份锁；宠物主体参考图 <2 张先引导补传。

## F1 爆款商品裂变

触发示例：把这个爆款裂变几个版本、这款多出几个变体、爆款改款。

编排（能力序列）：
```
S4 抠图（透明底）→ S2 侵权闸门 → S7/S6 多维裂变（色way/风格/构图/元素）→ S11 套图 → S13 交付检查
```
要点：
- 裂变维度默认四个：色way（换色板）、风格（换 style_token）、构图（换构图槽位）、元素（加减元素）；每维出 2–3 款。
- 所有裂变量子图共用同一透明底 Asset（S4 产出），保证主体一致。

## F2 系列套系裂变

触发示例：按这张图出一整个系列、做一套系列产品、系列套系。

编排：
```
S12 系列裂变（DNA 解析 + 槽位替换）→ S11 套图一致性 → S13 交付检查
```
要点：
- DNA 六件套：布局骨架 + 风格 embedding + 色板 + 字体 + slogan 句法树 + 主体槽位。
- 槽位替换维度：主体系列 / 文案系列 / 空间套系 / 双面配套 / 情侣套系。
- 双阈值闸门：风格距离 < τ1（0.15）且主体区分度 > τ2（0.35），不满足整组重跑。

## F3 关键词生成商品

触发示例：生成一款花卉印花、做个宠物主题商品、按关键词出一款。

编排：
```
S1 印花设计 → S2 侵权闸门 → S10 文字排版 → S13 交付检查
```
要点：S1 产出后立即过 S2（生成内容也要过合规），有文字需求才走 S10。

## F4 透明底印花提取

触发示例：把这件T恤的印花提取出来、成衣印花还原成平面稿。

编排：
```
S3 印花提取（去皱+去纹理）→ S4 抠图（透明底）→ S5 放大 → S13 交付检查
```
要点：S3 输出平面稿后，S4 抠掉白底得到透明底印花；S5 按需放大到印刷分辨率。

## F5 无缝拼接印花

触发示例：做成四方连续、无缝拼接、平铺循环印花。

编排：
```
S1/S3 印花稿 → 平铺校验 → 循环拼接 → S13 交付检查
```
要点：生成时 composition 用 `seamless tileable pattern, edges must align`；拼接后肉眼检查接缝。

## F6 宠物圣诞套系

触发示例：把我家狗做成圣诞套系、宠物圣诞主题一套。

编排：
```
S2 侵权闸门 → S4 抠图 → S7 圣诞拟人重绘 → S9 爪印提取 → S10 文字排版 → S11 套图（3件套）→ consistency_gate → S13 交付检查
```
要点：
- S7 走 P10 宠物拟人模板；参考图不足 2 张时先引导补传。
- S9 爪印来自 S4 透明底的 alpha，禁止本地 ML 分割。
- 套图 3 件套：主图（拟人全身）+ 爪印元素图 + 文字纪念图。

## F7 全家福油画墙

触发示例：全家福做成油画挂墙、一家人油画风。

编排：
```
S2 侵权闸门 → 多人分割（S4 逐人）→ S6 统一油画风 → S11 多构图套图 → S10 相框排版 → S13 交付检查
```
要点：多人身份锁按 bbox 分别注入，避免"脸串味"；style_token 统一 oil_painting。

## F8 情侣互补款

触发示例：情侣装一对、做互补情侣款。

编排：
```
S2 侵权闸门 → 双人分割（S4）→ 镜像构图 → 互补色板 → S10 互补文案 → S11 正反面套图 → S13 交付检查
```
要点：镜像构图保证左右呼应；色板用互补色对。

## F9 纪念时间轴

触发示例：把我们的照片做成时间轴、纪念册。

编排：
```
多图 EXIF 排序 → S10 模板排版（YOU&ME 时间轴）→ S13 交付检查
```
要点：读 EXIF 拍摄日期自动排序；日期缺失时让用户手动确认顺序。

## custom 流程拼装

当用户请求无法命中 F1–F9 时，由 P2 剧本规划器动态拼装：
- 输入：P1 看图 JSON + 用户原话 + 能力目录；
- 输出：steps DAG（见 prompts-l1.md P2 输出字段）；
- 拼装仍受上方通用规则 1–5 约束。

## 流程与单能力的衔接

- 用户先单独跑了某能力（如 S4 抠图），再说"用它做个套系"→ P0 判为 flow，P2 引用已有 Asset，跳过重复步骤。
- 流程中任一能力也可被单独抽出来再跑（如套系里对某张不满意，单独重跑 S7 那一步）。
