# agnes-studio 操作手册（能力 × 调优归口）

> 本手册把"能做什么 / 不满意调哪里 / 命令入口"三件事钉死，避免凭感觉乱改。
> 配套权威文档：`SKILL.md`（能力目录）、`capabilities.md`（S 能力配方）、`playbooks.md`（F 流程编排）、`prompts-l2.md`（P7 风格词库 / P8 身份短语 / P11 一致性）。
> 本手册本地文件，默认不推送 GitHub。

---

## 0. 怎么用这本手册

- **两种触发模式**（由 L1 路由器 `mllm_task.py --task p0_route` 判定）：
  - `mode=single`：用户点名单一能力（抠图/放大/换风格/提取印花/查侵权/加文字…）→ 走对应 **S** 能力固定管线。
  - `mode=flow`：用户描述目标型结果（"做一套""出一个系列""圣诞套系"）→ 命中预置 **F1–F9** 流程。
- **核心铁律**：任何"不满意"先定位是哪一维（风格 / 身份 / 构图 / 抠图 / 预设 / 文案），再决定改哪个文件——**风格问题才动 P7，其他维度动错了白改**。

## 2. "效果不满意" → 该调哪里（决策矩阵）

| 你真正不满意的点 | 该调的归口 | 误调 P7？ |
|------------------|------------|-----------|
| 风格不对 / 风格飘 / 某种风格效果差 | **P7 风格词库表**（改或加 `style_id` 行的 `style_token`） | —（正解） |
| 人不像 / 宠物变样 / 脸串味（身份漂移） | **P8 identity_lock_phrase**（S7/S8 重绘类） | ✗ 找错 |
| 构图 / 版面不好 | 构图槽位 / 套图规格（非风格） | ✗ 找错 |
| 抠图边缘 / 放大锐度 / 文字渲染 | 确定性脚本 `keycut`/`delivery_check`/`text_layout` + `gen.py` 参数 | ✗ 找错 |
| S3 印花提取形变 / 平整度 | S3 专用垫图 prompt（展开+去纹理） | ✗ 找错 |
| 引流广告预设效果（ad-reveal 等） | `gen.py` 里的 **PRESETS 字典**（代码层，另一套机制） | ✗ 找错 |
| ALT 文案 / 路由 / 合规判定 | `mllm_task.py` 的系统提示词常量 | ✗ 找错 |

**反馈闭环**：不满意 → 看 P4 质检 `style_match` 是否没过 → 是 → 回 P7 完善那个 `style_id` 的 `style_token` → 重跑；不是 → 按上表去别处。

## 3. 常见玩法归口（速查）

- **印花提取**：S3（单张）/ F4（带透明底+放大+交付）。
- **裂变**：S12（系列裂变）/ F1（爆款多维）/ F2（套系）/ F8（情侣）。
- **印花设计**：S1（从0生成）。
- **来图玩法**：S7（重绘）/ S8（替换）/ S3·S6（垫图改造）。
- **商品图→视频**：`gen_video.py` 文生/图生/关键帧 ✅；**视频脚本无专门能力**，需手动写 prompt（可借 `p1_understand` 分析来图 + `p5_copy` 出口播文案）。
- **系列图案**：
  - 连幅 → S11 套图 / F5 无缝拼接（四方连续）
  - 套装 → F2 系列套系 / F8 情侣互补（双面配套）
- **合影类**：现有最靠近 = F7 全家福油画墙 / F8 情侣互补款。（注：技能内无"超人"功能，用户曾提及但未定位，疑似记忆混淆/期望功能，待澄清后再决定是否新增。）

## 4. 调优安全线（改之前先看）

1. **P7 风格词库维护规则**（prompts-l2.md L56）：新增/修改风格必须先在 **10 张测试图**上验证保身份效果再入库；每个 `style_id` 附 **3 张效果样例**存档。改完不是随手改，要验证。
2. **风格词只能整段取用**（prompts-l1.md L170）：禁止自造风格词、一次只用一个主风格 token。所有风格走 P7，不手写进 prompt。
3. **分层铁律**：文字永远走 `text_layout.py` 由排版引擎渲染，**严禁把要出现的文字写进 positive_prompt**。
4. **禁止本地 ML 抠图**（SKILL L155）：rembg/BRIA/u2net 边缘不达标，一律不用；抠图走 S4（云端键色 + `keycut.py` 确定性转 alpha）。
5. **双端点双令牌**：`.com` 用 `AGNES_API_KEY`，`.cn` 用 `AGNES_API_KEY_CN`（各自环境）。改端点/key 看 `api-notes.md`，密钥不进脚本、不进仓库（`.gitignore` 已忽略 `.env`）。

## 5. 最小可用命令入口

```bash
# 路由：判断走单能力还是流程
python scripts/mllm_task.py --task p0_route --image 来图.jpg

# 单能力
python scripts/gen.py --prompt "..." --size 2048x2048 --output 印花稿.png   # S1
python scripts/gen.py --image 来图.jpg --prompt "..." --output 提取.png     # S3/S6/S7 垫图
python scripts/keycut.py -i 来图.png --key auto --output 抠图.png            # S4
python scripts/alt.py -i 来图.png -o alt.txt                                # ALT 文案
python scripts/text_layout.py --spec spec.json --base 底图.png --output 成品.png  # S10

# 视频（--image 支持本地路径，脚本自动转 base64）
python scripts/gen_video.py --prompt "..." --image 本地图.png --output url.txt

# 交付闸门
python scripts/delivery_check.py --input 成品.png --cmyk --target-width-mm 300
```

> 完整 47 能力计数与边界、实测进度，见 `SKILL.md` 末尾"实测进度"段。
